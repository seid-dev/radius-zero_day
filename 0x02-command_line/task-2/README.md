
# Task 2: File and Directory Management

## Objective

Practise creating, inspecting, copying, moving, renaming,
and removing files and directories using Git Bash.

## Commands Practised

- mkdir -p: Creates directories and parent directories.
- touch: Creates empty files.
- echo: Writes text to files.
- cat: Displays file contents.
- head: Displays the first lines of a file.
- tail: Displays the last lines of a file.
- wc -l: Counts the number of lines.
- cp: Copies files.
- mv: Moves and renames files.
- rm: Removes files.
- ls -l: Displays file details and permissions.
- find: Searches for files and directories.

## Difference Between > and >>

- > overwrites existing file contents.
- >> appends new content without removing existing contents.

## File Permissions

I used ls -l to inspect file permissions.

I learned that:

- r represents read permission.
- w represents write permission.
- x represents execute permission.
- - indicates that a permission is not granted.

## What I Learned

I learned how to create and organize directories,
manage file contents, copy and move files, rename files,
remove unnecessary files, and inspect basic permissions.
